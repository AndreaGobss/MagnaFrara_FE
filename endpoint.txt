Formati Comuni
Date: ISO 8601 (YYYY-MM-DDTHH:mm:ss.sssZ)
Valutazioni: Numero decimale da 1.0 a 5.0
Paginazione: page (default: 1), limit (default: 10)
Ordinamento: sort (asc | desc), sortBy (campo per ordinamento)
Struttura Risposte
// Successo
{
  "success": true,
  "data": { ... },
  "message": "Optional success message"
}

// Errore
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable error message",
    "details": { ... } // Optional
  }
}
